# 💰 FinanSmart

Uma aplicação web moderna de controle financeiro pessoal, desenvolvida como projeto de portfólio utilizando **Vibe Coding** (Lovable).

FinanSmart foi concebido para simplificar o gerenciamento das suas finanças pessoais, permitindo visualizar receitas, despesas e acompanhar gastos de forma clara e intuitiva.

---

## 🎯 Sobre o projeto

O **FinanSmart** é uma solução para quem deseja ter controle total sobre suas finanças pessoais de forma simples e eficiente.

**Objetivo:** Criar uma aplicação web responsiva que permita ao usuário gerenciar receitas e despesas, visualizar seu saldo, acompanhar gastos por categoria e obter insights sobre seus hábitos financeiros.

**Público-alvo:** Pessoas físicas que desejam organizar e acompanhar suas despesas e receitas pessoais.

**Desenvolvimento:** O projeto está sendo desenvolvido de forma **incremental e iterativa**, começando com um MVP (Produto Mínimo Viável) funcional, com planos de evolução contínua baseados em feedback e novas funcionalidades.

O projeto utiliza as seguintes tecnologias:

## 🗺️ Roadmap

### Fase 1: MVP Funcional (Em desenvolvimento)

**Objetivo:** Criar uma aplicação básica, mas completa, que permita o gerenciamento de receitas e despesas.

- Dashboard com indicadores financeiros principais
- Formulário para novo lançamento
- Listagem de lançamentos com filtros
- Operações CRUD (Criar, Ler, Atualizar, Deletar) para transações
- Persistência local de dados

### Fase 2: Autenticação e Dados Remotos (Planejado)

- Autenticação de usuários
- Banco de dados para sincronização remota
- Possibilidade de acessar dados de múltiplos dispositivos

### Fase 3: Integração Bancária (Planejado)

- Conexão com contas bancárias
- Importação de transações automática
- Controle de cartões de crédito e faturas

### Fase 4: Inteligência e Análise (Planejado)

- Relatórios avançados e gráficos interativos
- Metas financeiras personalizadas
- Assistente financeiro com IA para análise de hábitos

## 🤖 Visão Futura com Inteligência Artificial

O FinanSmart foi concebido com a evolução futura em mente, incluindo recursos avançados de **Inteligência Artificial** que **ainda não estão implementados**:

### Funcionalidades de IA planejadas:

- **Categorização Inteligente:** Classificação automática de despesas com base no histórico
- **Análise de Hábitos:** Identificação de padrões de gastos e comportamento financeiro
- **Detecção de Anomalias:** Alertas para gastos fora do padrão ou inusitados
- **Resumo Financeiro:** Geração automática de relatórios e insights
- **Recomendações Personalizadas:** Sugestões de economia baseadas no perfil
- **Interface de Linguagem Natural:** Interação por voz e chat com o assistente financeiro

Esses recursos irão transformar o FinanSmart em um assistente financeiro inteligente e intuitivo.
