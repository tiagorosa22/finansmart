Prompt para criar um app finaceiro pessoal pelo Lovable - Vibe coding


Crie uma aplicação web chamada FinanSmart, um sistema moderno de controle financeiro pessoal.

OBJETIVO
O FinanSmart deve permitir que o usuário controle suas receitas e despesas, visualize seu saldo e acompanhe seus gastos por categoria.

IMPORTANTE
Não implemente funcionalidades de IA nesta primeira versão.
Não implemente login nesta primeira versão.
Priorize uma aplicação funcional, limpa, responsiva e fácil de evoluir posteriormente.

TELAS

1. DASHBOARD

Criar uma página inicial contendo:

- Saldo atual
- Total de receitas do mês
- Total de despesas do mês
- Resultado financeiro do mês
- Gráfico de receitas x despesas
- Gráfico de despesas por categoria
- Lista das últimas transações

Utilizar cards visuais para os principais indicadores.

2. LANÇAMENTOS

Criar uma página para visualizar todos os lançamentos.

Cada lançamento deve apresentar:

- Data
- Descrição
- Tipo: Receita ou Despesa
- Categoria
- Forma de pagamento
- Valor
- Status

Adicionar filtros por:

- Período
- Tipo
- Categoria
- Status

Adicionar botões para:

- Novo lançamento
- Editar
- Excluir

3. NOVO LANÇAMENTO

Criar formulário contendo:

- Tipo: Receita ou Despesa
- Descrição
- Valor
- Data
- Categoria
- Forma de pagamento
- Status
- Observação

O formulário deve validar os campos obrigatórios.

FORMAS DE PAGAMENTO

- Dinheiro

STATUS

- Pago
- Pendente

REGRAS FINANCEIRAS

Receitas devem aumentar o saldo.

Despesas pagas devem diminuir o saldo.

Despesas pendentes não devem ser descontadas do saldo atual, mas devem aparecer no total de despesas pendentes.

O dashboard deve atualizar automaticamente após criar, editar ou excluir uma transação.

Criar uma interface:

- Moderna

- Fácil de usar

Criar uma barra lateral de navegação contendo:

- Dashboard

Utilizar uma identidade visual relacionada a finanças, transmitindo organização, confiança e tecnologia.

Não criar informações financeiras fictícias permanentes. Caso seja necessário utilizar dados de demonstração, deixar claramente identificado como dados de exemplo.

OBJETIVO

Garantir que o fluxo de lançamento financeiro esteja funcionando corretamente de ponta a ponta.

FLUXO ESPERADO

1. Usuário abre "Novo lançamento".
2. Seleciona Receita ou Despesa.
3. Preenche descrição.
4. Informa valor.
5. Seleciona data.
6. Seleciona categoria.
7. Seleciona forma de pagamento.
8. Seleciona status.
9. Salva o lançamento.
10. O lançamento deve aparecer imediatamente na tabela.
11. O Dashboard deve atualizar automaticamente.
12. O saldo deve ser recalculado.
13. Os gráficos devem refletir o novo lançamento.
14. O lançamento deve permanecer salvo após atualizar a página.

REGRAS

Receita paga:
+ valor no saldo.

Despesa paga:
- valor no saldo.

Receita pendente:
não deve alterar o saldo atual.

Despesa pendente:
não deve alterar o saldo atual.

Todos os lançamentos, pagos ou pendentes, devem continuar disponíveis para relatórios e consultas.

VALIDAÇÕES

- descrição vazia;
- valor igual a zero;
- valor negativo;
- categoria não selecionada;
- data inválida;
- tipo não selecionado.

Evitar problemas de cálculo causados por strings formatadas como moeda.
